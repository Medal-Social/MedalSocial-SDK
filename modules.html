      Medal Social SDK

      Official TypeScript SDK for the Medal Social API.

      Provides typed access to posts, emails, contacts, deals, GDPR compliance, helpdesk conversations, partner channel connect, webhooks, and workspace management. Works in Node.js, Deno, Bun, Cloudflare Workers, and modern browsers.

      Example

      import { Medal } from "@medalsocial/sdk";

      const medal = new Medal("medal_xxx");
      const { data: post } = await medal.posts.create({
        content: "Hello world!",
        channel_ids: ["ch_1"],
      });
