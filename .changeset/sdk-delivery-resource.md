Add `medal.delivery` for Wolt delivery from a restaurant's own online store: `addresses.suggest(query, { session?, signal? })` autocompletes a Norwegian address (up to 8, nearest the restaurant first), `addresses.resolve(id, { session?, signal? })` verifies the one the customer picked against Kartverket and answers its `address_id`, and `quotes.create({ address_id, venue_id?, bags?, prep_minutes?, order_total? }, { signal? })` gets a live, binding Wolt price with the restaurant's customer fee (`customer_fee`, `cost`, `eta_minutes`, `delivered_by`, `valid_until`). Pass the quote's `quote_id` and the resolved `address_id` to `ordering.orders.create({ channel: 'delivery', delivery: { verified_address_id, quote_id } })`. A quote is sent exactly once (no automatic retry), because every call asks Wolt for a fresh price and the server waits up to 20 s for it. Out-of-range input throws `RangeError` before any request. New types `DeliveryAddressSuggestion`, `DeliveryResolvedAddress`, `DeliveryAddressSource`, `DeliveryQuoteInput`, `DeliveryQuote`, `DeliveryMoney`, `DeliveryAddressOptions`, `DeliveryQuoteOptions`; `MedalErrorCode` gains `ADDRESS_LOOKUP_UNAVAILABLE`, `ADDRESS_NOT_DELIVERABLE`, `DELIVERY_NOT_SET_UP`, `DELIVERY_PAUSED`, `INVALID_REQUEST`, `NOT_DELIVERABLE`, `QUOTE_TIMEOUT` and `VENUE_UNAVAILABLE`.
