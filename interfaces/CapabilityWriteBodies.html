    Interface CapabilityWriteBodies

    Request body type for each confirmable capability.

    undefined for routes that take no request body (the DELETE routes, the GDPR export, a post publish). unknown for the confirmable routes this SDK has no method for: the id is still mintable, but the SDK cannot claim to know the payload's shape.
