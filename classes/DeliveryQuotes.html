      Ask Wolt for a binding delivery price to a verified address, with the restaurant's customer fee policy applied (Wolt's price, a fixed fee, or free over an order total). Resolves 201 with { quote_id, customer_fee, cost, eta_minutes, delivered_by, valid_until, address, venue_id }.

      Every call is a fresh Wolt quote, and the server waits up to 20 s for Wolt. The call is therefore sent exactly once — the SDK's automatic retry on 429/5xx would spend the 30/min quote budget and stack 20 s waits. Retry yourself when it makes sense (a 504 QUOTE_TIMEOUT, say). A client timeout under about 25 s can abort a quote that would have succeeded.

      For an online order: order_total must be the cart subtotal in øre and address_id the resolved address_id. Then pass the quote's quote_id and that same address_id to ordering.orders.create() as delivery: { verified_address_id, quote_id, … }. Make a new quote when the cart subtotal changes, and when valid_until is less than a minute away: the order is refused with 422 QUOTE_NOT_USABLE / QUOTE_EXPIRED otherwise.

      const { data: quote } = await medal.delivery.quotes.create({
        address_id: address.address_id,
        order_total: cart.subtotal_ore,
      });
      showFee(quote.customer_fee); // { amount: 4900, currency: "NOK" } or null

      await medal.ordering.orders.create(
        {
          ...order,
          channel: "delivery",
          payment_method: "vipps",
          return_url,
          delivery: { verified_address_id: address.address_id, quote_id: quote.quote_id },
        },
        { idempotencyKey: cart.idempotencyKey },
      );

      Errors: 400 INVALID_REQUEST, 409 DELIVERY_NOT_SET_UP / DELIVERY_PAUSED / VENUE_UNAVAILABLE, 422 ADDRESS_NOT_VERIFIED, 422 NOT_DELIVERABLE (Wolt cannot deliver there right now), 422 ADDRESS_NOT_DELIVERABLE (Wolt will not promise delivery to that address), 429 RATE_LIMITED, 504 QUOTE_TIMEOUT.

          A pre-order: the slot the customer picked, 1 hour to 7 days ahead (ISO 8601 with Z or an offset). The quote is for a dropoff at that time, and an order with timing.kind: scheduled takes only a quote made for its slot (else 422 QUOTE_NOT_USABLE). Omit for an order as soon as possible.
