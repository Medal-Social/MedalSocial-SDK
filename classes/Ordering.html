    Class Ordering

    Restaurant online ordering, for the restaurant's own site. Call it server-side with the workspace API key: scope ordering.storefront.read for the menu, locations, slots and tables; orders has its own scopes.

    A workspace without the online-ordering module answers every call with 403 ORDERING_NOT_ENABLED.

    locations

    • locations(request?: OrderingReadOptions): Promise<LocationsEnvelope>

      Every location that takes online orders, with each channel's state right now (enabled, open, and when closed the reason and next opens_at), payment methods, preorder_days and slot_minutes. Instants are ISO 8601 UTC; render them in data.time_zone.

      The API marks the response Cache-Control: private, no-store: the open state changes by the minute, so read it per request.

    menu

    • menu(
          options: OrderingMenuOptions,
          request?: OrderingReadOptions,
      ): Promise<OrderingMenuResult>

      What a guest can order on one channel at one instant: active dishes in open categories and time windows, with their modifier groups. Sold-out dishes and options stay listed with sold_out: true.

      The API marks the menu Cache-Control: private, no-store, so cache it yourself and revalidate with the ETag:

      const first = await medal.ordering.menu({ channel: "takeaway" });
      // later
      const next = await medal.ordering.menu({ channel: "takeaway", ifNoneMatch: first.etag });
      const menu = next.notModified ? cached : next.menu;

    slots

    • slots(
          options: OrderingSlotsOptions,
          request?: OrderingReadOptions,
      ): Promise<SlotsEnvelope>

      The pickup or delivery slots a guest can pick on one service date for one channel at one location. date is in the workspace time zone and must be today through today + the location's preorder_days (400 VALIDATION_ERROR otherwise); an unknown location is 404 NOT_FOUND. A channel that is off or a closed day gives an empty slots list.

      const { data } = await medal.ordering.locations();
      const loc = data.locations[0];
      const { data: day } = await medal.ordering.slots({
        location: loc.id,
        channel: "takeaway",
        date: "2026-10-21",
      });

    table

    • table(tableToken: string, request?: OrderingReadOptions): Promise<TableEnvelope>

      Resolve the token in a table's QR code to its location and label, so the site can open the dine-in menu for that table and send the token with the order as table_token. The token is URL-encoded into the path. An unknown or archived table is 404 TABLE_NOT_FOUND. Scope ordering.storefront.read; the response is private, no-store.

      const { data } = await medal.ordering.table(searchParams.get("t") ?? "");
      // { location_id: "loc_1", table_label: "12" }
